# REST API BizOps Lab

## Overview

This project demonstrates how Business Operations teams can use Python and REST APIs to retrieve, process, and report on operational data.

The project connects to a public REST API, retrieves JSON data, processes the response, generates KPI reports, exports CSV reports, and stores raw JSON data for analysis.

## Technologies Used

* Python
* REST APIs
* Requests Library
* JSON
* CSV
* Business Operations Reporting

## Project Components

### API Connectivity

* HTTP GET Requests
* API Response Validation
* JSON Data Retrieval

### Data Processing

* JSON Parsing
* Data Transformation
* KPI Calculations

### Reporting

* CSV Report Generation
* KPI Summary Reports
* Raw JSON Export

## Files Generated

### users_report.csv

Business-friendly report containing:

* User ID
* Name
* Username
* Email
* Company

### api_kpi_summary.txt

Operational KPI summary including:

* Total Users Retrieved
* Unique Companies
* Unique Cities

### users_raw.json

Raw API response data stored for auditing and analysis.

## Business Use Case

This project simulates how Business Operations and Operations Engineering teams consume external API data, transform it into operational reports, generate KPIs, and provide actionable insights to stakeholders.
